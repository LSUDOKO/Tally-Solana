# Tally-Solana

Let your agent pay, only for what tallies. Built for the MLH Solana Hackathon (AI Track).

Package manager: pnpm.

## Commands

- build: `pnpm build`
- test: `pnpm test`
- build: `cargo build`
- test: `cargo test`

## Layout

- `app/`
- `crates/`
- `docs/`
- `mcp/`
- `programs/`
- `scripts/`
- `sdk/`
- `tests/`

## Rules

- Run `pnpm test` before you say a change is done.
- Never commit secrets or `.env` files.
